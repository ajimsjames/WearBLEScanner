# WearBLEScanner

WearBLEScanner is a high-performance Bluetooth Low Energy (BLE) scanning utility for Wear OS smartwatches.

## Features
- Real-time BLE advertising device detection and RSSI scanning\n- Interactive radar-like status representation\n- Pure black AMOLED theme matching circular bezel contours

## Installation
Install directly via the [WearAppStore](https://github.com/ajimsjames/WearAppUpdater) client on your watch.

- **Namespace**: `com.ajimsjames.wearblescanner`
